# Project Overview

This project is organized into separate areas:

- `backend/`: Backend services, APIs, data access, and server-side logic.
- `frontend/`: User interface, client-side state, components, and styling.
- `infra/`: Infrastructure, deployment, and operations configuration.
- `infra/terraform/`: Terraform configuration for cloud resources.
- `docs/business/`: Business requirements, workflows, domain terms, and rules.

Agents should keep changes scoped to the relevant area unless the task explicitly requires cross-area changes.
