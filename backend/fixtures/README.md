# Synthetic demo dataset

All names, IDs, account numbers, addresses, transactions, and policies in this folder are fictional. They are designed solely for the SHB hackathon MVP.

Scenarios:

- `unsecured_happy_path`: clean unsecured SME working-capital loan.
- `collateral_missing_owner_evidence`: ownership mismatch triggers Needs Info and selective re-plan.
- `policy_changed_after_approval`: policy version invalidates an approval token before commit.
